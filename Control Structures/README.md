# PLSQL Control Structures

This folder contains example PL/SQL scripts demonstrating basic control structures.

Files:
- `if_statement.sql`: simple `IF` statement
- `if_else_statement.sql`: `IF` / `ELSE` logic
- `case_statement.sql`: `CASE` statement for conditional selection
- `loop_statement.sql`: unconditional `LOOP` with `EXIT WHEN`
- `while_loop.sql`: `WHILE` loop
- `for_loop.sql`: `FOR` loop
- `nested_loop.sql`: nested `FOR` loops

Usage:
1. Open a PL/SQL-capable SQL client (SQL*Plus, SQL Developer, etc.).
2. Enable `DBMS_OUTPUT` if needed.
3. Run the desired script file.
