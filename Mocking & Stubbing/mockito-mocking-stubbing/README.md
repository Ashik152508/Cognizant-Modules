# Mockito Mocking and Stubbing Example

This sample project demonstrates basic Mockito mocking and stubbing in a small Java Maven application.

## Structure

- `src/main/java/com/example/UserService.java` - service interface
- `src/main/java/com/example/UserManager.java` - class under test
- `src/test/java/com/example/UserManagerTest.java` - JUnit/Mockito tests

## Run tests

```bash
mvn test
```
